# Portfolio-crazyej

This portfolio is a simple personal website built to showcase my work, skills, and projects. It uses plain HTML, CSS, and JavaScript to create a modern landing page and a dedicated projects page.

## Overview

The portfolio has two main pages:

- Index.html — the main landing page or home page
- projects.html — a page that presents selected projects and experience

The design uses a dark, modern aesthetic, smooth motion effects, and a clean structure that makes it easy to present work professionally.

## How I created the portfolio

### 1. Started with a landing page
I created the home page in Index.html to introduce myself and highlight:

- my name and role
- a short description
- links to project work
- a contact section
- navigation buttons for resume and projects

This page acts like the first impression of my portfolio.

### 2. Built a project showcase page
I created projects.html to display each project with:

- project title
- short description
- technologies used
- role or contribution
- links to GitHub, demo, or case study

This helps visitors understand what I have built and what I can do.

### 3. Used HTML for structure
Each page is built with semantic HTML sections such as:

- nav
- hero/header
- main content
- project cards
- footer

This keeps the layout organized and improves readability.

### 4. Used CSS for styling
The portfolio styling is done inside each HTML file using embedded CSS. I used:

- color schemes
- spacing and layout
- typography
- card design
- hover effects
- responsive design for smaller screens

This makes the site look polished without needing a framework.

### 5. Added JavaScript for motion and interaction
JavaScript was used for:

- animated background effects
- contact modal interactions
- scroll-based animation
- hover and dynamic visual effects

This creates a more engaging portfolio experience.

## Best way to build your own portfolio

### Step 1: Define your purpose
Before designing, decide what your portfolio should show:

- your skills
- your projects
- your work experience
- your personal brand

### Step 2: Prepare your content
Write your personal information clearly:

- full name
- short bio
- role or field (Web Developer, Data Analyst, Computer Science Student, etc.)
- contact information
- GitHub and LinkedIn links

### Step 3: Create the structure
Start with a simple structure like:

- home page
- about section
- projects page
- contact section

### Step 4: Design the pages
Keep the style clean and modern. Some good principles:

- use a dark or minimal theme
- keep text readable
- highlight project work
- keep navigation simple
- make it mobile-friendly

### Step 5: Add your projects
Each project should include:

- title
- short summary
- problem solved
- technologies used
- result or impact
- GitHub/demo link

## How to do your projects

A strong portfolio project should follow this format:

### Project idea
Choose work that shows what you can do. Good examples:

- school project
- internship task
- personal app
- landing page
- automation tool
- API or dashboard
- website redesign

### Project process
For every project, explain:

1. Problem or goal
2. What you built
3. Technologies used
4. Challenges faced
5. How you solved them
6. Final result

### Example project description

Project Name: Student Task Manager

- Built a web app for managing class tasks and deadlines
- Used HTML, CSS, JavaScript, and local storage
- Designed a simple UI to help students stay organized
- Added features such as task creation, deletion, and filtering
- Result: a simple but functional productivity app

This format makes your project look professional and easy to understand.

## Suggested project card format

Use this structure for each project card:

- Project title
- Role: Solo / Team / Internship
- Description: what it does and why it matters
- Tags: HTML, CSS, JavaScript, Python, React, etc.
- Link: GitHub or live demo

## How to customize this portfolio

You can personalize the current portfolio by changing:

- the name in the hero section
- your short description
- project titles and descriptions
- social links and contact information
- colors and fonts
- resume link

If you want to update your project list, edit the content inside projects.html and adjust the section cards to match your actual work.

## How to run the portfolio locally

### Option 1: Open directly in browser

- open Index.html in your browser
- or open projects.html separately

### Option 2: Use Live Server in VS Code

- open the project folder in VS Code
- right-click Index.html
- select Open with Live Server

This makes it easier to see live updates while editing.
